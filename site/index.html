About this map

p2irl is a crowdsourced map of how posting2 users know each other.

How it works: add yourself with your exact posting2 handle and list the people you know. Each connection gets a color for how it formed:

  • IRL — you know each other from real life
  • posting2 then IRL — met on the app, then in person
  • posting2 only — so far, anyway

Anyone you mention who hasn't joined yet appears as a dashed unconfirmed node until they claim it, and a line stays dashed until both people report it.

Ground rules: handles only — no real names, no locations, no private info. Only add connections that actually exist, labeled honestly. Exact spelling matters; there's no directory lookup, so typos create duplicates.

Want off the map? Contact @dang on posting2 and your node will be removed, no questions asked.
